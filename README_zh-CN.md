# OOMOL 文件操作

为 OOMOL 工作流提供的全面文件和文件夹管理模块集合,无需编写代码即可处理常见的文件操作。

## 这个包是什么?

**OOMOL File** 是一个工具包,为您的 OOMOL 工作流提供处理文件和文件夹的基础模块。无论您需要从互联网下载文件、在文件夹之间复制文档,还是将数据转换为文件,这些模块都能让操作变得简单直观。

---

## 使用场景

此包非常适合:

- **内容自动化**: 从 URL 下载图片、视频或文档并自动整理
- **文件整理**: 根据工作流需求复制、移动和整理文件和文件夹
- **数据管理**: 将二进制数据转换为文件或从现有文件中提取二进制内容
- **批量处理**: 一次处理多个文件,按类型筛选,并对整个文件夹应用操作
- **网络集成**: 从网络 URL 下载内容并保存为本地文件

---

## 可用模块

### 📥 下载与导入

#### **URL 转文件 (URL to File)**
从网络 URL 下载内容并保存为文件。

**使用场景**: 当您需要从互联网下载图片、文档或任何文件时。

**功能特性**:
- 自定义下载位置
- 设置自定义请求头和查询参数
- 配置超时和重试次数
- 选择保留原始文件名或重命名

---

#### **URL 转二进制 (URL to Binary)**
从 URL 下载内容并输出为二进制数据(不保存到磁盘)。

**使用场景**: 当您需要在保存之前在内存中处理下载的内容时。

**功能特性**:
- 支持查询参数
- 自定义请求头
- 超时和重试配置

---

#### **文件转二进制 (File to Binary)**
读取文件并将其内容转换为二进制数据。

**使用场景**: 当您需要在内存中处理文件内容或将其传递给另一个模块时。

---

### 💾 保存与导出

#### **二进制转文件 (Binary to File)**
将二进制数据写入文件,完全控制保存位置。

**使用场景**: 当您有二进制内容(来自下载或处理)需要保存时。

**功能特性**:
- 指定确切的文件名和位置
- 如果文件夹不存在,自动创建
- 选择文件已存在时的行为:覆盖、忽略、重命名或抛出错误

---

#### **二进制另存为文件 (Binary Save As File)**
快速保存二进制内容,配置最少。

**使用场景**: 当您想要简单的"另存为"对话框体验时。

**功能特性**:
- 可选的自定义保存路径
- 使用自定义后缀自动生成文件名

---

### 📂 文件与文件夹管理

#### **复制文件 (Copy File)**
将单个文件从一个位置复制到另一个位置。

**使用场景**: 当您需要将文件复制到不同文件夹时。

---

#### **批量复制文件 (Copy Files)**
一次将多个文件复制到目标文件夹。

**使用场景**: 当您需要在一个操作中复制多个文件时。

---

#### **复制文件夹 (Copy Folder)**
将整个文件夹及其所有内容复制到新位置。

**使用场景**: 当您需要复制完整的文件夹结构时。

---

#### **清空文件夹 (Empty Folder)**
删除文件夹内的所有内容(但保留文件夹本身)。

**使用场景**: 当您需要在处理新内容之前清空文件夹时。

⚠️ **警告**: 这将永久删除指定文件夹内的所有文件和子文件夹。

---

### 🔍 文件发现与筛选

#### **列出文件夹中的文件 (List Files from Folder)**
从文件夹中检索所有文件路径。

**使用场景**: 当您需要获取要处理的文件列表时。

**功能特性**:
- 按文件名自然排序
- 可选的递归子文件夹搜索
- 在绝对路径和相对路径之间选择
- 如果文件夹不存在,返回空数组(不报错)

---

#### **筛选文件 (Filter Files)**
按类型(图片、视频、音频、PDF)筛选文件列表。

**使用场景**: 当您有混合的文件列表并只需要特定类型时。

**支持的类型**:
- **图片**: .jpg, .jpeg, .png, .gif, .bmp, .webp, .svg 等
- **视频**: .mp4, .avi, .mov, .mkv, .wmv, .flv 等
- **音频**: .mp3, .wav, .flac, .aac, .ogg, .wma 等
- **PDF**: .pdf 文档

**功能特性**:
- 可选择过滤隐藏文件

## 常见工作流示例

### 示例 1: 下载并整理图片
```
1. URL 转文件 → 从网络下载图片
2. 复制文件 → 将其移动到整理好的文件夹
```

### 示例 2: 批量处理文档
```
1. 列出文件夹中的文件 → 获取所有文件
2. 筛选文件 → 只保留 PDF
3. 批量复制文件 → 将筛选的文件复制到输出文件夹
```

### 示例 3: 网络内容收集
```
1. URL 转二进制 → 下载内容
2. 二进制转文件 → 使用自定义名称保存
3. 复制文件 → 整理到分类文件夹
```

### 示例 4: 文件夹清理和刷新
```
1. 清空文件夹 → 清除输出目录
2. 列出文件夹中的文件 → 获取新的源文件
3. 批量复制文件 → 用新鲜内容填充输出
```

## 安装

此包在 OOMOL 市场中提供。只需将其添加到您的项目依赖中:

```yaml
dependencies:
  oomol-file: latest
```

或通过 OOMOL 界面搜索 **"OOMOL File Operations"** 进行安装。

## 最佳使用技巧

1. **在列出文件后使用筛选文件** 以仅处理您需要的文件类型
2. **在下载模块中启用重试选项** 以实现可靠的网络下载
3. **在二进制转文件中选择"重命名"选项** 当您不想覆盖现有文件时
4. **在列出文件中启用递归搜索** 以处理嵌套的文件夹结构
5. **在处理之前始终使用清空文件夹进行测试** 以确保输出目录干净
